# 👻 GhostIT

IT-ассистент для собеседований (разработка, QA, DevOps, аналитика) для Windows: слушает вопросы по горячей клавише или голос собеседника прямо из видеозвонка (системный звук) и мгновенно выдаёт ответы ИИ в оверлее поверх всех окон.

GhostIT — оверлей, который не отвлекает: ответы появляются в компактном окне поверх других приложений, его можно сделать «кликом сквозь окно», а при записи экрана — полностью скрыть.

## Возможности

- **Вход через Telegram за 5 секунд** — кнопка «🔑 Войти через Telegram»: QR или кнопка «Подключить» в боте, тариф подтягивается сам
- **Голосовые вопросы по горячей клавише** — зажми `Ctrl+Shift+Space`, говори, отпускай (режимы hold / toggle / автослушание)
- **Слышит собеседника из любого звонка** — автослушание захватывает системный звук (Zoom/Meet/Telegram/Teams), а не только микрофон
- **Понимает, где вопрос** — распознанный фрагмент анализируется: на вопросы интервьюера ответ выдаётся сразу, обычные реплики пропускаются
- **Локальное распознавание речи** — Whisper работает офлайн (tiny/base/small/medium), ничего не уходит в облако
- **Быстрые ответы** — через облако GhostIT (демо-тариф бесплатно), свой Groq/OpenRouter/локальный ключ или любая OpenAI-совместимая модель
- **Помнит контекст** — отвечает на уточнения («а почему так?»), история вопросов/ответов сохраняется и экспортируется в файл
- **Оверлей поверх всех окон** — компактный интерфейс, живая визуализация звука
- **Скрывать от записи экрана** — окно не видно в записях и демонстрациях (WDA_EXCLUDEFROMCAPTURE)
- **Озвучка ответов (TTS), клик сквозь окно, автообновление**

## Системные требования

| Параметр | Минимум | Рекомендуется |
|---|---|---|
| **ОС** | Windows 10 x64 (1809+) / Windows 11 | Windows 10/11 x64 |
| **Процессор** | 2 ядра | 4+ ядра |
| **ОЗУ** | 4 ГБ | 8 ГБ |
| **Место на диске** | ~700 МБ свободно | 1+ ГБ |
| **Видеокарта** | любая (встроенная подходит) | любая |
| **Микрофон** | нужен для голосового ввода | — |
| **Интернет** | нужен для ответов ИИ (LLM API) | — |

> Почему такие требования: приложение построено на Electron (сам по себе ~300–500 МБ ОЗУ), а локальная модель Whisper занимает ~250 МБ на диске и ещё ~500 МБ в памяти во время распознавания. Вместе с видеозвонком 4 ГБ — рабочий минимум.

**Совет для слабых ПК:** в настройках выбери модель Whisper **tiny** или **base** — распознавание станет в 2–4 раза быстрее (немного ниже точность). Распознавание идёт на процессоре (GPU не нужен), поэтому на слабом CPU вопрос может обрабатываться 5–15 секунд — окно при этом не зависает.

## Горячие клавиши

| Комбинация | Действие |
|---|---|
| `Ctrl+Shift+Space` | Зажать и говорить (настраивается в ⚙️) |
| `Ctrl+Shift+H` | Показать / скрыть оверлей |
| `Ctrl+Shift+K` | Клик сквозь окно (не мешает другим приложениям) |

Режимы активации: **hold** (зажал — говоришь), **toggle** (нажал — говоришь — нажал), **автослушание** (без клавиши), **hold + авто**.

## Как это работает

1. **Голос** — микрофон или системный звук (слышит собеседника в звонке)
2. **Распознавание** — Whisper выполняется локально в отдельном процессе (UI не тормозит)
3. **Детектор вопроса** — фрагмент анализируется на вопросительные слова и «?»
4. **Ответ** — LLM (облако GhostIT или свой ключ) со стримингом прямо в оверлей
5. **Контекст** — предыдущие вопросы/ответы учитываются, история сохраняется

## Настройка

- **Быстро:** «🔑 Войти через Telegram» в настройках — Base URL, токен и модель подставятся сами из бота @GhostIT
- **Вручную:** ⚙️ Настройки → Base URL / API-ключ / модель (любая OpenAI-совместимая: Groq, OpenRouter, DeepSeek, локальный Ollama и т.д.)
- Остальное: модель Whisper, язык, чувствительность автослушания, источник звука (mic/system), TTS, прозрачность, скрытие от записи, горячая клавиша

## FAQ / Устранение неполадок

- **Чёрный экран или артефакты** — в трее сними галку «Скрывать от записи экрана»; если экран погас, верни рабочий стол: `Ctrl+Shift+Esc` → «Файл» → «Запустить новую задачу» → `explorer.exe` (или `Win+Ctrl+Shift+B`)
- **«Клик сквозь окно» случайно включился** — нажми `Ctrl+Shift+K` или кнопку 🖱 в шапке
- **Медленное распознавание** — выбери модель Whisper tiny/base
- **Иероглифы в тексте меню** — старая сборка, обновись до последней версии
- **Нет ответа** — проверь тариф/API-ключ и Base URL в настройках
