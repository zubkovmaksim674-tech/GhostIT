# 👻 GhostIT

IT-ассистент для собеседований (разработка, QA, DevOps, аналитика) для Windows: слушает вопросы по горячей клавише или голос собеседника прямо из видеозвонка (системный звук) и мгновенно выдаёт ответы ИИ в оверлее поверх всех окон.

## Возможности

- **Вход через Telegram за 5 секунд** — кнопка «🔑 Войти через Telegram»: QR или кнопка «Подключить» в боте, тариф подтягивается сам
- **Голосовые вопросы по горячей клавише** — зажми `Ctrl+Shift+Space`, говори, отпускай (hold / toggle / автослушание)
- **Слышит собеседника из любого звонка** — автослушание может захватывать системный звук (Zoom/Meet/Telegram/Teams), а не только микрофон
- **Локальное распознавание речи** — Whisper работает офлайн (tiny/base/small/medium)
- **Быстрые ответы** — через облако GhostIT (демо-тариф бесплатно), свой Groq/OpenRouter/локальный ключ или любая OpenAI-совместимая модель
- **Оверлей поверх всех окон** — компактный интерфейс, живая визуализация звука
- **Скрывать от записи экрана** — окно не видно в записях и демонстрациях (WDA_EXCLUDEFROMCAPTURE)
- **История сессий, озвучка ответов (TTS), клик сквозь окно, автообновление**

## Скачать

Самая свежая версия: [releases/latest](https://github.com/zubkovmaksim674-tech/ghostqa/releases/latest)

- **GhostIT-Setup-x.y.z.exe** — установщик: выбери папку установки, ярлыки создадутся автоматически
- **GhostIT.exe** — portable: один файл, можно запустить откуда угодно, умеет самообновляться

> ⚠️ Windows может показать предупреждение SmartScreen («Необходимо проявить осторожность»), т.к. exe не подписан кодовой подписью. Нажми «Подробнее» → «Выполнить в любом случае».

## Запуск из исходников

```
npm install
npm start
```

## Сборка

```
npm run dist   # -> dist/GhostIT.exe (portable) + GhostIT-Setup-*.exe
```

## Настройка

Достаточно «🔑 Войти через Telegram» в настройках — остальное (Base URL, токен, модель) подставится само из бота @GhostIT. Без Telegram можно вручную: ⚙️ Настройки → Base URL / API-ключ / модель.
