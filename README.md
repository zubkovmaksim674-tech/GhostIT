# 👻 GhostQA

QA-ассистент для Windows: слушает вопросы по горячей клавише (или в фоне) и мгновенно выдаёт ответы ИИ в оверлее поверх всех окон.

## Возможности

- **Голосовые вопросы по горячей клавише** — зажми `Ctrl+Shift+Space`, говори, отпускай (режимы: hold / toggle / автослушание)
- **Локальное распознавание речи** — Whisper работает офлайн (tiny/base/small/medium)
- **Ответы от любой OpenAI-совместимой модели** — укажи Base URL, API-ключ и модель в настройках
- **Оверлей поверх всех окон** — компактный интерфейс в стиле GhostGPT, живая визуализация звука
- **Скрывать от записи экрана** — окно не видно в записях и демонстрациях (WDA_EXCLUDEFROMCAPTURE)
- **История сессий, озвучка ответов (TTS), клик сквозь окно**

## Скачать

Самая свежая версия: [releases/latest](https://github.com/zubkovmaksim674-tech/ghostqa/releases/latest) — файл `GhostQA.exe` (portable, установка не нужна).

> ⚠️ Windows может показать предупреждение SmartScreen («Необходимо проявить осторожность»), т.к. exe не подписан кодовой подписью. Нажми «Подробнее» → «Выполнить в любом случае».

## Запуск из исходников

```
npm install
npm start
```

## Сборка

```
npm run dist   # -> dist/GhostQA.exe (portable)
```

## Настройка

Первый запуск: ⚙️ Настройки → укажи Base URL / API-ключ / модель (например, OpenAI, OpenRouter, Groq или локальный Ollama), скачай модель Whisper — и всё готово.
